# ADR-001: Aplicación web responsive

- **Estado:** Aceptada según la descripción de arquitectura.
- **Contexto:** Administradores, entrenadores y acudientes deben acceder desde computador, tableta o móvil, sin requerir publicación en tiendas.
- **Decisión:** Construir una aplicación web responsive.
- **Alternativas:** Aplicaciones móviles nativas independientes; escritorio exclusivamente.
- **Justificación:** Un único cliente web reduce la duplicación y permite acceso multiplataforma.
- **Consecuencias:** Deben validarse usabilidad, accesibilidad, navegadores y distintos tamaños de pantalla.
