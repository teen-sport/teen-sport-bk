# ADR-004: Angular y Spring Boot con Java

- **Estado:** Aceptada según la descripción de arquitectura.
- **Contexto:** Se necesita frontend por componentes y backend robusto para reglas, seguridad y persistencia.
- **Decisión:** Angular/TypeScript para frontend; Java/Spring Boot para backend.
- **Alternativas:** React/Vue; Node.js, .NET o Python para backend.
- **Justificación:** Ecosistemas maduros, soporte de componentes, seguridad, REST y persistencia.
- **Consecuencias:** El equipo mantiene dos ecosistemas. La versión exacta de Java, Spring Boot y dependencias debe tomarse del build aprobado, no inferirse de este ADR.
