# Documentación del backend

- Utilizar Javadoc para documentar clases y métodos relevantes.
- Documentar las reglas de negocio complejas, las restricciones y las decisiones no evidentes.
- No generar comentarios redundantes que repitan el nombre o la implementación de un método.
- Mantener OpenAPI/Swagger actualizado con los endpoints, DTO, parámetros, respuestas y errores.
- Actualizar los documentos de arquitectura cuando cambie una decisión arquitectónica aprobada.
- Actualizar la trazabilidad cuando se implemente o modifique un requisito.
- Documentar las configuraciones necesarias sin incluir secretos.
- Mantener las instrucciones de ejecución y pruebas alineadas con el código real.
